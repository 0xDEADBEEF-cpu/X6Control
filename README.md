# X6 Control

Локальное приложение для настройки мыши **Attack Shark X6** на macOS. Интерфейс открывается в отдельном окне приложения. Для обычного использования Python, браузер и сетевой сервер не нужны.

Приложение предназначено для macOS и требует подключённую Attack Shark X6 или комплектный приёмник 2,4 ГГц.

## Возможности

- **DPI:** 6 уровней с шагом 50 и выбор активного уровня.
- **Частота опроса:** 125, 250, 500 или 1 000 Гц.
- **RGB-подсветка:** 7 режимов, настройка цвета, скорости и таймера сна.
- **Точность сенсора:** настройка выравнивания угла, сглаживания дрожания, высоты отрыва и debounce.
- **Кнопки:** переназначение семи физических кнопок.
- **Профили:** локальное сохранение настроек, применение выбранной группы параметров и сброс.
- **USB HID:** подтверждение от мыши для каждой отправленной команды.

Поддерживаются проводная X6 (`1d57:fa61`) и комплектный 2,4-ГГц-приёмник (`1d57:fa60`). Bluetooth и редактор макросов не поддерживаются.

> **Важно:** X6 не предоставляет чтение сохранённых настроек. Приложение показывает локальный профиль и сообщает о подтверждении отправленной команды, но не считывает конфигурацию непосредственно из мыши.

## Установка

1. Открой раздел **Releases** этого репозитория.
2. Скачай ZIP или DMG последнего релиза.
3. Перенеси `X6 Control.app` в папку «Программы».
4. Подключи мышь по USB или через её приёмник 2,4 ГГц и запусти приложение.

Приложение рассчитано на **macOS 13 и новее**, поддерживаются Intel и Apple Silicon. Настройки профилей хранятся локально в:

`~/Library/Application Support/X6 Control/profiles.json`

### Предупреждение macOS

Релизная сборка подписывается ad-hoc и не проходит нотарификацию Apple. Поэтому Gatekeeper может показать предупреждение при первом запуске. Локально приложение можно открыть через контекстное меню Finder: **Открыть**.

Для подписи сертификатом Developer ID сборочный скрипт поддерживает переменную `SIGNING_IDENTITY`. Для полноценной нотарификации потребуется отдельно настроить учётные данные Apple и соответствующий шаг GitHub Actions.

## Сборка из исходников

Понадобятся macOS, Xcode Command Line Tools и штатные инструменты `swiftc`, `xcrun`, `codesign`, `ditto` и `hdiutil`.

Сборка приложения для текущей архитектуры:

```sh
scripts/build-macos.sh native
```

Универсальная сборка для Intel и Apple Silicon:

```sh
scripts/build-macos.sh universal
```

Создание ZIP, DMG и контрольных сумм SHA-256:

```sh
scripts/package-macos-release.sh
```

Готовое приложение появится в `dist/X6 Control.app`.

## Запуск веб-интерфейса в режиме разработки

Исходный интерфейс можно открыть в браузере через локальный сервер:

```sh
python3 server.py
```

Нужны Python 3 и штатный компилятор Swift. Сервер по умолчанию слушает только `127.0.0.1:8765`. Изменить порт можно так:

```sh
python3 server.py --port 8766
```

## Публикация релиза

Автоматическая сборка и публикация релизов через GitHub Actions пока не настроена в опубликованной версии репозитория.

Когда workflow будет добавлен, релиз можно будет запускать отправкой Git-тега. До этого момента команды ниже не запустят автоматическую сборку:

```sh
git tag v1.0.0
git push origin v1.0.0
```

## Как устроено приложение

Нативная оболочка использует **AppKit** и **WKWebView**, а встроенный Swift-помощник отправляет HID-отчёты через macOS IOKit. Сетевой API в приложение не встроен: команды обрабатываются локально на этом Mac.

Изменения сначала сохраняются в локальном профиле и отправляются мыши только после применения.
